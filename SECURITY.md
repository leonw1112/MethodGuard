# Security policy

## Supported versions

MethodGuard has not released a supported version yet.

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in a public issue. Contact the repository owner privately through GitHub.

## Sensitive laboratory data

Never attach or commit:

- patient or personally identifiable information;
- production laboratory data;
- credentials, tokens, or license files;
- proprietary vendor projects without authorization;
- internal network paths or infrastructure details.

Reproductions should use the smallest possible synthetic fixture.

## Safety notice

MethodGuard is intended to support engineering analysis. It does not replace method validation, quality assurance, regulatory review, or instrument safety procedures.
